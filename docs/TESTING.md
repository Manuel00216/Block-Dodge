# Testing

Record date, device, OS, build, result and relevant issue for each test.

- [ ] Touch movement and UI input work across screen sizes and safe areas.
- [ ] Obstacles have reachable safe routes and warnings are clear.
- [ ] Collisions register once, including at low frame rates.
- [ ] Level objectives and each star result are accurate.
- [ ] Unlocks, best stars, settings and high scores survive restart.
- [ ] Pause, app interruption, resume and retry work correctly.
- [ ] Android and iOS builds run on physical devices.
- [ ] Frame pacing, memory, heat and battery use are acceptable on representative devices.

No gameplay or mobile build tests have been completed.
