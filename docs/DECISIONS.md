# Decisions

## 2026-11-27 — Project foundation

- Use a separate Unity Universal 2D project with Unity 6000.3.23f1, which is already installed with Android support.
- Target portrait Android and iOS play. iOS build verification requires a Mac and Xcode.
- Start with local progress and high scores. Online features can be considered later.
- Use a public GitHub repository as requested.
- First review milestone is five Jungle levels with a map, stars and saved progression.
